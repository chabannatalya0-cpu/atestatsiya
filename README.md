# Картка вивчення педагогічного досвіду (атестація)

Інтерактивна картка для педагогічних працівників КЗ «Василівський ліцей «Сузір'я»», які атестуються у 2026/2027 н. р.

- Сторінка для вчителів: `index.html` (GitHub Pages).
- Відповіді надходять у Google Таблицю заступника директора через вебзастосунок Apps Script (`apps-script/Code.gs`): рядок у таблиці, окремий Google Документ з карткою і лист-сповіщення.
- Чернетка зберігається в браузері вчителя; повторне надсилання оновлює ту саму картку.

Нормативна основа: Положення про атестацію педагогічних працівників (наказ МОН від 09.09.2022 № 805 зі змінами), Професійний стандарт «Вчитель закладу загальної середньої освіти» (наказ МОН від 29.08.2024 № 1225).
